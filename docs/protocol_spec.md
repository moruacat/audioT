# AudioT 协议规范

本文档描述 AudioT 数据链路层的帧结构、调制参数与前向纠错（FEC）配置。
所有多字节字段均为**大端序**（高位字节在前），比特流按字节 **MSB first** 展开。

## 1. 音频帧结构

### 1.1 文本帧（TextCodec）

```
偏移  长度   字段        说明
0     1     SYNC_H      固定 0xAA
1     1     SYNC_L      固定 0x55
2     2     LEN         DATA 长度（大端，LEN_HI, LEN_LO）
4     N     DATA        UTF-8 文本负载
4+N   2     CRC16       DATA 的 CRC-16/CCITT（大端）
```

- 总帧长 = 6 + N 字节
- CRC 仅覆盖 DATA 段；CRC 校验失败时接收端丢弃该帧
- 字节→比特展开为 MSB first（每字节 bit7 先发）

### 1.2 文件帧（FileCodec）

```
偏移  长度   字段        说明
0     1     SYNC_H      0xAA
1     1     SYNC_L      0x55
2     1     TYPE        0=通用 1=文本 2=图像 3=视频
3     1     FLAGS       保留标志位（分片序号/末片标记等）
4     2     NAME_LEN    文件名长度（大端）
6     N     NAME        文件名（UTF-8）
6+N   4     DATA_LEN    负载长度（大端，32 位）
10+N  M     DATA        文件负载
…     4     CRC32       全帧（除 CRC 自身）的 CRC-32
```

- 大文件经 `encodeFileChunked` 切分为默认 4096 字节/片的多个帧

## 2. 调制参数

### 2.1 AFSK（默认数据链路）

Bell 202 风格，相位连续正弦，Goertzel 解调。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 采样率 | 44100 Hz | 单声道 |
| Mark 频率 | 1200 Hz | 比特 1 |
| Space 频率 | 2200 Hz | 比特 0 |
| 波特率 | 1200 baud | 1 bit/符号 → 净荷 1200 bps（无 FEC）|
| 前导码 | 32 bit | 交替 0/1，用于同步与 AGC 稳定 |
| 后导码 | 16 bit | 全 0，帧结束标志 |

帧空中结构：`[前导 32bit][FEC 比特流（含文本帧）][后导 16bit]`

### 2.2 MFSK（4-FSK，FFT 判决）

基于 FFT 的正交多音调制：每个符号在 M=4 个正交频点中选一，携带 2 bit。
解调对每符号加 Hann 窗后做 FFT，取幅度最大的频点 bin 判决；多相窗口
搜索完成符号同步，容忍前导静音与时序偏移。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 采样率 | 44100 Hz | 单声道 |
| 基频 | 1500 Hz | 最低频点 |
| 符号率 | 见档位 | 稳健/均衡/高速三档 |
| 阶数 | 2 bit/符号 | 4-FSK（M=4）|

**档位**（符号率与正交频点间隔）：

| 档位 | 符号率 | 样本/符号 | bin 分辨率/频点间隔 | 净荷(无 FEC) |
|------|--------|-----------|----------------------|-------------|
| 稳健 | 50/s | 882 | 50 Hz | ≈ 100 bps |
| 均衡(默认) | 100/s | 441 | 100 Hz | ≈ 200 bps |
| 高速 | 150/s | 294 | 150 Hz | ≈ 300 bps |

频点间隔 = `sampleRate / samplesPerSymbol`，保证每个档位符号周期为整数
样本、频点落在整数 FFT bin 上（正交、无频谱泄漏）。高速档吞吐更高但
对噪声更敏感。

**自动检测**：接收端默认依次尝试 AFSK 与 MFSK 解调，任一方解出合法帧
（同步头 + CRC 校验通过）即采用 —— 无需双方预先协调调制方式。

### 2.3 PSK / QAM（已归档 beta/）

PSK 与 QAM 调制器实现均为**未经验证的实验代码**，已从主源码移除，归档至
`beta/` 目录，当前不提供支持，不参与收发链路。

### 2.4 链路预算参考（AFSK 默认配置）

- 无 FEC：1200 bps 原始比特率
- Hamming(7,4)：码率 4/7 → 有效吞吐 ≈ 685 bps
- 文本帧开销：6 字节头/帧

## 3. FEC 配置

### 3.1 Hamming(7,4)（默认链路 FEC）

- 4 个数据比特 → 7 个编码比特（码率 4/7）
- 纠正 1 bit 错误，检测 2 bit 错误
- 输入长度须为 4 的倍数（管线自动补 0）
- 表驱动实现：编码表 16 项、伴随式表 8 项

### 3.2 Reed-Solomon（块级纠错）

- 域：GF(2^8)，本原多项式 x^8+x^4+x^3+x^2+1（0x11D）
- 默认纠错能力 t = 8（附加 2t = 16 个校验字节）
- 解码流程：伴随式 → Berlekamp-Massey → Chien 搜索 → Forney 算法
- 适用场景：突发错误、文件传输的块级保护

### 3.3 LDPC（实验性）

- 默认参数 n = 256, k = 128（码率 1/2，系统码 [info | parity]）
- 解码：Min-Sum 置信传播，默认最多 50 次迭代
- 支持硬判决输入与 LLR 软判决输入

### 3.4 FEC 使用约定

| 链路 | 默认 FEC |
|------|----------|
| AFSK 文本链路（TxPipeline） | Hamming(7,4)，`PipelineConfig.useFEC = true` |
| 文件/图像传输 | FileCodec CRC32 + 可选 RS(t=8) |
| SSTV | 无 FEC（依赖模拟 FM 容噪，图像可降级接收） |

## 4. 音频格式约定

| 参数 | 值 |
|------|-----|
| 采样格式 | 32-bit float（内部，-1.0 ~ 1.0）|
| WAV 持久化 | 16-bit PCM，单声道 |
| 默认采样率 | 44100 Hz |
| 默认声道 | 1（单声道） |
| 默认缓冲 | 1024 采样 |
