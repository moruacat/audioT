## 1. 软件简介

AudioT 是一款**音频数据通信软件**：将**文本或文件**调制为音频信号，通过**扬声器、磁带机、电台**等音频链路传输；接收端用**麦克风采集**或 **WAV 文件解析**还原数据。

典型应用：

| 场景 | 说明 |
|---|---|
| 磁带机传输 | 数据导出为 WAV 音频，用磁带机录制并回放，另一台电脑从录音中还原 |
| 电台/近距离声波通信 | 一台电脑从扬声器发射，另一台电脑用麦克风监听解码，类似步话机 |
| 抗干扰传输 | 内置纠错编码，对麦克风电流声、环境噪声、磁带机失真有一定抵抗能力 |

## 2. 安装与卸载

### 2.1 系统要求

- **操作系统**：Windows 7 及以上（支持 32/64 位）
- **声卡**：任意支持 44.1 kHz 采样的输入/输出设备（板载声卡即可）

### 2.2 安装

运行 `AudioT-Setup.exe`，按向导操作：

1. **组件选择页**：
   - **AudioT 主程序**（必需，不可取消）
   - **Audacity 64 位 / 32 位**（可选，二选一）：配套音频编辑软件，用于录音、查看波形、裁剪噪声。勾选其一自动取消另一个
2. **安装目录**：默认安装到当前用户的 `%LOCALAPPDATA%\Programs\AudioT`（无需管理员权限），可点击"浏览"修改
3. 安装完成后自动运行 AudioT

安装完成后，桌面和开始菜单会生成 **AudioT** 快捷方式；若安装了 Audacity，也会生成对应快捷方式。

> **提示**：Audacity 组件安装时会自动解压并配置，可能需要十几秒，请勿中断。

### 2.3 卸载

两种方式任选：

- 开始菜单 → **AudioT 卸载**（Uninstall）
- 控制面板 → 程序和功能 → 找到 "AudioT - 音频数据通信" → 卸载

## 3. 界面总览

主窗口由左侧工作区与右侧常驻的**设置面板**组成：

```
┌──────────────────────────────────────────────┬──────────────┐
│  AudioT - 音频数据通信                        │  音频设置     │
├──────────────────────────────────────────────┤  (全局)       │
│  ┌────────────────────────────────────────┐  │   输入设备    │
│  │  波形监视器（实时显示输入信号波形）        │  │   输出设备    │
│  └────────────────────────────────────────┘  │   刷新设备    │
│  ┌────────┬────────┬────────┐                │   采样率      │
│  │  发射   │  接收   │  电台   │ ← 三个功能标签页 │   缓冲区      │
│  ├────────┴────────┴────────┤                │              │
│  │  当前标签页内容            │                │  当前任务参数 │
│  └──────────────────────────┘                │  （跟随选项卡）│
│  状态栏：全局事件与短暂反馈（见下）              │              │
└──────────────────────────────────────────────┴──────────────┘
```

- **波形监视器**：实时显示输入设备（麦克风）采集到的信号波形，发射时也可看到扬声器回授（保持黑底绿线的独立配色，不受主题影响，采用限频局部重绘）
- **设置面板**：位于主窗口右侧，常驻显示，分为**音频设置（全局）**与**当前任务参数（跟随选项卡）**两区（见第 7 节）
- **状态栏**：只显示**全局事件与短暂反馈**（如"发射已开始""已导出 WAV""解析失败"）；持续推进的状态（如"发射中 · 42%"）显示在对应的任务面板里，两处不会显示同一句话。错误提示会保留在任务面板，不会几秒后自动消失

### 3.1 界面主题

全应用使用**深色主题**（正式主题，主色 `#1585C0`）：

- 主色用于**当前页签下划线、主要操作按钮、输入焦点边框**
- 输入框/按钮圆角 5~8px，分组卡片圆角 8~10px；复选框为圆角方框并带清晰勾选
- **交互反馈**：按钮悬浮时用平滑渐变着色（不是瞬间跳变），点击按钮或切换复选框时有 90~260ms 的淡入淡出确认感；缓动曲线为 InOutQuad，覆盖层只作用于单个控件，不产生全窗口重绘
- 主题不使用阴影、渐变背景与半透明面板，转场动画仅限上述局部反馈，以降低弱机与 32 位系统上的渲染开销
- 主题色不作为唯一的状态表达：错误/成功都同时有图标化配色与明确文字（如"发射失败: …"）

## 4. 发射面板（发送数据）

发射面板用于**生成并播放**携带文本/文件数据的音频信号，或将信号**导出为 WAV 文件**。

### 4.1 操作步骤（文本发送）

1. 选择输入模式 **文本**
2. 在文本框中输入要发送的内容（如 `Hello world`）
3. 按需选择调制配置（见 4.3）
4. 点击 **开始发射**
5. 听到约 1 秒的 **1200 Hz 连续蜂鸣（准备音）** 后，数据开始发射；进度条显示发射进度
6. 发射完成后面板显示"发射完成"

### 4.2 文件发送

1. 选择输入模式 **文件**
2. 点击 **选择文件…** 选择要发送的文件（任意类型，推荐小于 100 KB）
3. 点击 **开始发射**

接收端解出文件后会自动保存（见第 5、6 节）。

### 4.3 调制配置（发送前设置）

| 选项 | 可选值 | 说明 |
|---|---|---|
| 调制方式 | **AFSK（默认）** / MFSK (4-FSK) / PSK (差分) / 16-QAM | 见 4.3.1 对比 |
| MFSK 档位 | 稳健 / **均衡（默认）** / 高速 | 仅选择 MFSK 时显示 |
| PSK 阶数 | DBPSK / **DQPSK（默认）** / D8PSK | 仅选择 PSK 时显示 |
| PSK/QAM 档位 | 稳健 / **均衡（默认）** / 高速 | 仅选择 PSK 或 16-QAM 时显示 |
| 纠错编码 | None / **Hamming（默认）** / Reed-Solomon | 见第 8 节 |
| 采样率 | 22050 / **44100（默认）** / 48000 | 采样率越高音质越好、抗噪越强，文件越大 |

#### 4.3.1 四种调制方式对比

| 调制方式 | 每符号比特 | 特点 | 适用场景 |
|---|---|---|---|
| **AFSK** | 1 | 频移键控（1200/2200 Hz），成熟稳定，默认 | 通用；磁带机、电台 |
| **MFSK (4-FSK)** | 2 | 四个正交频点中选一，FFT 峰值判决，抗窄带干扰强 | 噪声较大的链路 |
| **PSK (差分)** | 1 / 2 / 3 | 差分编码 + 非相干差分解调，**不需要载波相位锁定** | 中等质量链路，速率高于 AFSK |
| **16-QAM** | 4 | 幅度与相位联合调制，前导符号兼作导频做信道估计 | 信道质量良好时追求高吞吐 |

> 收发双方应使用**相同的采样率、调制方式、纠错编码**；若用 MFSK 还须选相同**档位**，用 PSK 还须选相同**阶数**，用 PSK / 16-QAM 还须选相同**档位**，否则无法解码。

### 4.4 导出 WAV

- 点击 **导出 WAV**，选择保存路径，即可将信号导出为 WAV 文件（**不含发射环节**，与"开始发射"是两个独立步骤）
- 导出的 WAV 与实时发射**结构完全相同**（准备音 → 数据 → 帧尾静音），可直接用磁带机录制，或用接收面板解析
- 用于磁带机场景：导出 → 用磁带机播放录音 → 另一台电脑播放磁带录音并录制为 WAV → 接收面板解析

### 4.5 注意事项

- **发射提示随状态变化**（不再有常驻红字）：
  - 空闲时：提示"发射时输出设备将播放调制音频，请先确认输出设备与音量"（灰色）
  - 准备音阶段：提示"正在播放准备音，请确认输出设备与音量"
  - 发射阶段：提示"正在播放编码音频，请勿将音量调至过高"
  - 出错时才显示红色提示，并保留在面板状态栏
- 发射期间可随时点击 **停止发射** 立即中止（准备音阶段、以及"编码中"阶段同样立即取消）
- **大文件不会卡界面**：点击"开始发射"后先显示 **"编码中..."**（调制在后台线程进行），编码完成才进入准备音/数据发射；期间界面照常可操作，可点"停止发射"取消
- 实时发射时请确保**输出设备**（扬声器）音量足够且未被静音
- 切换输入模式（文本 / 文件 / 图片视频）**不会清空已输入的内容**，切回后内容仍在

## 5. 接收面板（解析 WAV 文件 / 麦克风实时接收）

接收面板支持**两种输入模式**：解析已录制好的 WAV 文件（离线解码），或直接用麦克风实时接收。

### 5.1 输入模式选择

- **WAV 文件**：解析已录制的录音文件（如磁带机回放的录音）
- **麦克风（实时）**：实时监听麦克风，检测到信号自动切段解码；**解出完整数据后自动停止监听**

> 麦克风实时模式与电台模式监听互斥（共享同一输入设备）：在接收面板开始监听会自动停止电台监听，反之亦然。

### 5.2 WAV 文件解析

1. 选择输入模式 **WAV 文件**
2. 在"WAV 文件"栏点击 **选择文件…** 选择录音文件
3. 点击 **解析 WAV**
4. 解析成功后：
   - **文本消息**：显示在"接收内容"区域
   - **文件消息**：自动弹出保存对话框，默认文件名与发送端一致
5. 解析失败时状态栏显示失败原因（如"未找到信号"、"CRC 校验失败"），该提示保留在接收面板状态栏，不会几秒后自动消失

### 5.3 麦克风实时接收

1. 选择输入模式 **麦克风（实时）**，按钮变为"开始监听"
2. 点击 **开始监听**（状态显示"监听中..."，进度条为忙碌动画）
3. 对方从扬声器发射数据 → 本机麦克风捕获 → 自动切段解码
4. 解出完整数据后**自动停止监听**，文本显示在"接收内容"区域（文件消息弹出保存对话框）
5. 若检测到信号但未解出数据，状态栏提示"检测到信号但未解出数据"，可点击 **停止监听** 手动结束监听

### 5.4 提示

- 支持的 WAV 格式：PCM 16 位，22050 / 44100 / 48000 Hz，单/双声道均可（双声道自动取左声道）
- 录音建议：录制完整信号（准备音 + 数据 + 尾部静音），不要裁剪掉准备音
- 麦克风实时接收前，请在设置中确认**输入设备**选择正确（设置 → 输入设备）
- 接收结果区提供 **保存结果**（把当前显示内容写入文件）与 **清空结果**（只清除面板显示内容，**已保存到磁盘的文件不受影响**）两个按钮；结果为空时"清空结果"自动禁用
- 与电台模式监听互斥：输入设备被对方占用时，本页会明确显示"已停止：输入设备被电台监听占用"，不会两个页面同时显示"监听中"

## 6. 电台面板（实时双向通信）

电台面板提供**类似聊天软件的双向通信**：一台电脑即一个"电台站"，通过扬声器发射、麦克风监听，两台电脑可同时收发（收发互不影响）。

### 6.1 操作步骤（两台电脑）

1. **双方**进入"电台"标签页
2. 双方点击 **开始监听**（麦克风采集开始，状态栏显示"监听中..."）
3. 任一方在输入框输入文本，点击 **发送**：
   - 先发出 1 秒准备音蜂鸣，随后是调制数据
   - 消息以**绿色气泡（右侧）**显示在自己一侧
4. 对方监听到信号后自动切段解码，消息以**灰色气泡（左侧）**显示；**时间戳与气泡旁置**（己方在气泡左侧、对方在气泡右侧），与气泡同属一个整体
5. 系统信息（监听状态、发送失败、信号未解出等）以**居中灰字**显示

### 6.2 发送文件

- 点击 **发送文件…** 选择文件 → 会先弹出**发送确认**（显示文件名、大小、当前调制方式与 FEC），确认后才开始传输；取消则不改动输入框与发送状态
- 接收方解出后自动保存到系统**「下载」目录**，并在聊天记录中以**文件气泡**显示

**文件气泡上的两个动作是分开的**：

| 点击位置 | 动作 |
|---|---|
| **文件名**（可点击文本） | 用系统默认程序打开该文件；文件不存在或系统没有默认打开程序时给出明确提示 |
| **气泡其余区域** | 查看文件消息详情（文件名、类型、大小、保存位置） |

- 气泡内会显示**文件大小与保存状态**（如"1.2 MB · 已保存到 Download"）
- **同名文件不覆盖**：下载目录里已有同名文件时，自动保存为"文件名 (1).ext"等
- **保存失败**（权限不足、磁盘满、文件名非法）时，气泡不会显示为可打开的文件，而在聊天区以居中灰字给出具体失败原因

### 6.3 注意事项

- **收发设备分离**：发送走输出设备（扬声器），接收走输入设备（麦克风），因此发射期间监听照常进行
- **距离与音量**：两台电脑的扬声器与麦克风距离越近、音量越大，成功率越高；建议 1~3 米内
- 同一台电脑上可开启"监听"后自收自发（回环测试），用于验证链路是否正常
- 电台模式使用麦克风实时监听，请先在设置中确认输入设备正确

### 6.4 发送中的状态与停止

- 发送期间：输入框、**发送文件…** 按钮与"调制参数"选项全部**变灰**（禁止调节），发送按钮变为 **停止发送**，并在下方显示**发射进度条**
- 点击发送后先显示 **"编码中..."**（调制在后台线程进行，界面不冻结），编码完成才进入准备音与数据发射
- 停止策略按风险区分：
  - **文本消息**：点击 **停止发送** 立即中止，不做无谓确认
  - **文件消息**：点击 **停止发送** 会先弹确认，并显示"已发送约 x%、剩余约 y%"
  - **编码中**（尚未上air）：直接取消，实际未向对方发出任何内容，因此也不会发停止通知
- 中止后会**尝试**向对方发送一条 **"[发送已停止]"** 通知；但通知本身也是一次传输，若信道已断可能发不出去。此时本机会在聊天区明确提示"本机已停止发送，但通知未能发出，对方可能仍在等待"——**"本机停止成功"与"对方收到通知"是两个不同的结果**，不会假装对方已收到

## 7. 设置面板（设备与参数）

设置面板**常驻在主窗口右侧**，无需弹窗；其中的音频设备与全局音频参数**修改即时生效**（发射/监听进行中不宜修改）。
面板分为两个区，用于区分**参数归属**：

- **音频设置**（全局）：音频设备 + 全局音频参数（采样率、缓冲区），对发射 / 接收 / 电台**都生效**
- **当前任务参数**（任务级）：只对**当前选项卡**生效，标题会显示任务名（如"当前任务参数（发射）"）；切换选项卡时，这一区自动切换为对应任务的参数

### 7.1 音频设置（全局）

| 选项 | 说明 |
|---|---|
| 输入设备 | 麦克风/录音设备（电台监听、实时接收用） |
| 输出设备 | 扬声器/耳机（发射用） |
| 刷新设备 | 重新枚举系统音频设备（插拔声卡后点击） |
| 采样率 | 22050 / **44100（默认）** / 48000 Hz；需与发射端一致 |
| 缓冲区 | 256 / 512 / **1024（默认）** / 2048 / 4096 samples；越小延迟越低，出现爆音/卡顿时调大 |

- **输入设备状态**会显示在该区：空闲，或"正被『电台』/『接收』任务占用"（输入设备在同一时刻只能被一个监听任务使用）
- 采样率与缓冲区**不再折叠隐藏**，因为它们经常直接决定任务成败

> 首次打开设置时自动枚举设备，可能耗时 1~2 秒。虚拟声卡（如 VB-CABLE）也会出现在列表中。

### 7.2 当前任务参数（跟随当前选项卡）

> **这些参数只属于当前任务**：切到"发射 / 接收 / 电台"任一选项卡，面板即显示该选项卡自己的调制高级参数（其中 AFSK 显示 Mark/Space/波特率，MFSK 显示档位，PSK 显示阶数与档位，16-QAM 显示档位，其余项自动隐藏），并且**各任务互不影响**（同一组控件不再在每个选项卡里重复出现）。

| 选项 | 可选值 | 说明 |
|---|---|---|
| Mark 频率 | **1200 Hz（默认）** | **AFSK 专用**：代表二进制 1 的载波频率 |
| Space 频率 | **2200 Hz（默认）** | **AFSK 专用**：代表二进制 0 的载波频率 |
| 波特率 | **1200 bps（默认）** | **AFSK 专用**：符号速率，越低抗噪越强、传输越慢 |
| MFSK 档位 | 稳健 / **均衡（默认）** / 高速 | **MFSK 专用**：稳健↔高速的取舍 |
| PSK 阶数 | DBPSK / **DQPSK（默认）** / D8PSK | **PSK 专用** |
| PSK/QAM 档位 | 稳健 / **均衡（默认）** / 高速 | **PSK / 16-QAM 专用** |

> **Mark / Space / 波特率仅对 AFSK 生效**：MFSK 由"档位"决定符号率与频点，PSK / 16-QAM 由"PSK/QAM 档位"决定符号率与载波（载波自动取符号率的 2 倍），这三项对它们不起作用。

### 7.3 调制参数（位于"发射 / 接收 / 电台"各选项卡内）

每个收发选项卡都有独立的"调制参数"组，可各自设置、互不影响（各自的配置会分别保存）：

| 选项 | 可选值 | 说明 |
|---|---|---|
| 调制方式 | **AFSK（默认）** / MFSK (4-FSK) / PSK (差分) / 16-QAM | 四种，对比见 4.3.1 |
| MFSK 档位 | 稳健 / **均衡（默认）** / 高速 | 仅选择 MFSK 时显示 |
| PSK 阶数 | DBPSK / **DQPSK（默认）** / D8PSK | 仅选择 PSK 时显示 |
| PSK/QAM 档位 | 稳健 / **均衡（默认）** / 高速 | 仅选择 PSK 或 16-QAM 时显示 |
| 自动检测调制方式 | 勾选（默认）/ 取消 | **仅接收端**；开启后自动尝试四种调制 |
| FEC 类型 | None / **Hamming（默认）** / Reed-Solomon | 见第 8 节 |

**速率与载波速查**（采样率 44100 Hz）：

| 调制方式 | 稳健 | 均衡（默认） | 高速 |
|---|---|---|---|
| MFSK (4-FSK) | 50 符号/s ≈ 100 bps | 100 符号/s ≈ 200 bps | 150 符号/s ≈ 300 bps |
| PSK (差分) 符号率 | 735 符号/s | 1050 符号/s | 1470 符号/s |
| 16-QAM 符号率 | 735 符号/s | 1050 符号/s | 1470 符号/s |
| PSK /16-QAM 载波 | 1470 Hz | 2100 Hz | 2940 Hz |

> PSK 的净速率 = 符号率 × 阶数（DBPSK ×1 / DQPSK ×2 / D8PSK ×3）；16-QAM 净速率 = 符号率 × 4。
> 发射端不显示"自动检测"选项（那是接收端能力）。
> 载波频率不单独提供输入框，它由档位自动设定——任意载波若与符号率不成整数倍，会造成符号内的正交积分泄漏而无法解调。

### 7.4 纠错编码（FEC）

| 选项 | 默认 | 说明 |
|---|---|---|
| FEC 类型 | **Hamming** | None / Hamming / Reed-Solomon，见第 8 节 |

### 7.5 配置文件

所有设置持久化在同一个可移植的 INI 文件（纯文本、可直接查看/备份）：

- Windows：`%APPDATA%\AudioT\audioT.ini`
- Linux：`$XDG_CONFIG_HOME/AudioT/audioT.ini`

内容分组：

| 分组 | 内容 |
|---|---|
| `[audio]` | 输入/输出设备、采样率、缓冲区大小 |
| `[modem:tx]` `[modem:rx]` `[modem:radio]` | 各选项卡的调制方式、FEC、自动检测，以及调制高级参数（Mark/Space/波特率、档位、阶数） |

> 删除该文件即可恢复全部默认设置（各处在文件缺失时回退默认值）。

## 8. 纠错编码说明

音频链路（扬声器→麦克风、磁带机）存在不可避免的符号级错误（噪声、失真、爆音），纠错编码可显著提升解码成功率。

| 方案 | 纠错能力 | 数据开销 | 抗突发错误 | 推荐场景 |
|---|---|---|---|---|
| None | 无（1 位错误整帧作废） | 0% | 弱 | 仅无噪声数字链路（如直接拷贝 WAV 文件） |
| **Hamming(7,4)** | 每 7 位码字可纠 1 位 | +75% | 弱 | **短文本消息（默认，推荐）** |
| Reed-Solomon(255,239) | 每 255 字节块可纠 8 个错误字节 | +6.7% | **强** | **大文件传输** |

**选择建议**：

- **短消息（文本）**：用 **Hamming**。开销虽大但短消息总时长可接受，且对单点错误有纠正能力
- **大文件**：用 **Reed-Solomon**。RS 按 239 字节分块，开销小、抗连续错误强，适合长时传输
- 若链路质量很好（近距离、无噪声），可尝试 None 获得最短传输时间；失败率高时换回 Hamming

> 注：RS 对不足 239 字节的短消息会填充补位，导致传输时间变长，故短消息不推荐 RS。

## 9. 典型应用场景

### 9.1 磁带机传输（离线存储）

1. 发送端：发射面板输入文本 → **导出 WAV** → 用磁带机录制该 WAV 到磁带
2. 运输磁带到目标电脑
3. 目标电脑：磁带机播放 → 声卡录制为 WAV（可用 Audacity）→ **接收面板解析**

### 9.2 电台/近距离声波通信（实时）

1. 双方打开**电台**标签页，分别点击 **开始监听**
2. 一方输入文本/选择文件 → **发送**
3. 另一方自动解码显示，可立即回复 → 双向对话

### 9.3 回环自测（验证链路）

- 单台电脑：设置中确认输入/输出设备 → 电台页开始监听 → 发送文本 → 应看到自己的消息被解码回显（绿色 + 灰色各一条）
- 若回环成功而远距离失败，说明是链路衰减/噪声问题，可降低波特率或调近距离

## 10. 技术规格

| 项目 | 规格 |
|---|---|
| 调制方式 | AFSK / MFSK(4-FSK) / PSK(差分) / 16-QAM |
| 默认参数 | Mark 1200 Hz、Space 2200 Hz、1200 bps、44100 Hz |
| 符号长度 | 36 样本 @ 44100 Hz |
| **MFSK 参数** | 4-FSK，符号率 50 / 100 / 150 符号/s，相邻频点间隔等于符号率（正交） |
| **PSK 参数** | 差分 PSK（DBPSK/DQPSK/D8PSK），符号率 735 / 1050 / 1470 符号/s（默认 1050），载波 = 2 × 符号率（默认 2100 Hz），前导 32 符号 |
| **16-QAM 参数** | 16-QAM（Gray 映射），符号率同 PSK 档位，前导 32 符号兼作导频做信道估计 |

| 帧头 | AA 55 |
| 类型帧 | 'T'（文本）/ 'F'（文件） |
| 校验 | CRC-16/CCITT（0x1021，初值 0xFFFF） |
| 纠错 | Hamming(7,4) / Reed-Solomon(255,239)，可关闭 |
| 支持格式 | 文本（UTF-8）、任意文件（≤ 100 KB 建议） |
| 音频格式 | PCM 16 位，22050 / 44100 / 48000 Hz，单/双声道 |

## 11. 常见问题排查

### 11.1 解码失败 / 解不出内容

按顺序检查：

1. **听一听录音**：应有"1 秒连续蜂鸣（准备音）+ 滋滋调制声"结构。若听到断续/卡顿/噼啪，说明发送端播放或录音链路有问题（设备欠载、音量过低）
2. **音量**：发送端输出音量和接收端输入音量适当调大（但避免削波失真——波形监视器顶部出现平顶即过载）
3. **参数一致**：确认收发双方采样率、调制方式、FEC 设置完全一致；若用 AFSK 还要 Mark/Space 频率与波特率一致，若用 MFSK 还要**档位**一致，若用 PSK 还要**阶数**一致，若用 PSK / 16-QAM 还要**档位**一致
4. **录音完整**：确认录音包含准备音和数据部分，未从数据中间开始
5. **环境噪声**：远离风扇、空调等噪音源；使用磁带机时避免磁头脏污
6. **换 FEC**：失败时改选 Hamming（默认）重试；仍失败再试 None/RS 对比
7. **降低速率**：链路质量差时降低速率档位——AFSK 降低波特率（如 600 bps），MFSK / PSK / 16-QAM 改选"稳健"档，抗噪能力显著提升

### 11.2 声音断续 / 卡顿

- 增大设置中的**缓冲区大小**（如 1024 → 4096）
- 关闭其他占用声卡的软件（浏览器、播放器等）
- 确认音频驱动正常（设备管理器中声卡无感叹号）

### 11.3 电台监听不到信号

- 确认输入设备选择了正确的麦克风（设置 → 刷新设备）
- 发送方距离过远：拉近至 1~3 米
- 波形监视器应能看到信号波形；若完全平直，说明输入链路不通

### 11.4 安装后无法启动

- 确认安装的是完整组件（主程序为必选）
- 尝试右键 → 以管理员身份运行（个别系统需要）
- 卸载后重新安装最新版本

### 11.5 虚拟声卡（VB-CABLE 等）使用

- 在设置中将输入/输出设备分别指向虚拟声卡对应端点
- 虚拟声卡方案用于"无声传输"（扬声器不发声），但会引入额外延迟和爆音风险，优先推荐真实声卡链路
